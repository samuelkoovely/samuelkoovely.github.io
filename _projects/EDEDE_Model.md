I am developing an original statistical model for temporal networks. Its preliminary name is the Ascona model, and I plan to use to it generate syntethic data to test change-point detection algorithms for graphs time series. The method relies on queueing processes and it's particularly suited for generating link streams with non-0 duration links/events.

In particular, I focus on a Markovian parametrization of the model, which allow to semple structures with Exponentially-Duration Links Distanced Exponentially (EDLDE structures).

Most of the results on this topic can be read in this
<a href="https://arxiv.org/pdf/2512.16972">article</a>.
